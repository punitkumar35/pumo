# pumo

Pumo Technovation — IT training institute website (static prototype).

Live preview: https://pumotechnovation.com/

## Stack
- Static HTML + CSS (Bootstrap 5.3.3, Swiper 11, Bootstrap Icons)
- Google Fonts: Readex Pro, Raleway, Big Shoulders Display

## Run locally
```
python -m http.server 8000
# open http://localhost:8000/
```

## Pages
- index.html — Homepage
- courses.html — IT Courses
- placement.html — Placements
- about.html / blog.html / careers.html / contact.html
- our-branches-and-courses.html
- Legal: privacy-policy, terms-and-conditions, refund-policy, cancellation-policy
